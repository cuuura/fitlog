# v1.0 계약 — Android MVP 출시

v0.1~v0.3 계약에 **더하는** 계약이다. WP는 이 계약을 바꾸지 않는다. 바꿔야 하면 트랙 리드에게 올린다.

| 파일 | 내용 | 주 사용자 |
| --- | --- | --- |
| `openapi.yaml` | STA-4 그래프 API(종목 추이, 회차 비교), 공개 페이지(/privacy, /account-deletion) | A1, B1 |
| `security.md` | Play Integrity 헤더, 서버 모드(off/report/enforce), 호출 제한(429) | A2, B2, B3 |
| `privacy-policy.md` | 개인정보 처리방침 본문. 서버가 빌드 시 읽어 `/privacy` HTML로 렌더링. `{{CONTACT_EMAIL}}` 자리표시자 | A2·A3(렌더링), B2(스토어 등록) |

## 결정 사항
- 그래프 데이터는 서버가 집계한다(계산은 서버). 앱은 오프라인이면 "연결 후 볼 수 있음"을 보여준다
- 추이는 세션당 1점. 끝낸(completedAt 있음) 작업 세트만 쓰고 워밍업·삭제·무게나 횟수 없는 세트는 뺀다. 추정 1RM은 1~10회 세트만, 사용자 설정 추정식
- PR 표시는 그 시점까지의 누적 최대보다 **엄격히 큰** 경우만
- 회차 비교의 "지난 같은 세션"은 같은 프로그램 인스턴스·같은 day이면서 그 종목이 들어 있는 직전 세션, 없으면 그 종목을 한 직전 세션
- 무결성 검증은 인증 경로(`/v1/auth/google`, `/v1/auth/refresh`)에만 건다. 앱은 토큰을 못 얻어도 헤더 없이 보낸다(서버 모드가 막을지 결정)
- 문의 이메일·백업 보관 기간 같은 운영 값은 서버 환경 변수로 넣는다

## v1.0 완료 기준 (MVP)
1. AI로 만든 프로그램을 JSON이나 MCP로 넣고 바로 운동을 시작할 수 있다.
2. 세션을 실시간으로 기록하면 다음 회차 무게가 규칙대로 계산된다.
3. 종목별로 지난 세션·PR과 비교한 그래프를 볼 수 있다.
4. 본인이 4주 동안 다른 앱 없이 이 앱만으로 운동을 기록한다.
