# fitlog 개인정보 처리방침

시행일: {{EFFECTIVE_DATE}}

fitlog(이하 "앱")는 운동 기록을 저장하고 프로그램 무게를 계산하기 위해 필요한 최소한의 개인정보만 처리합니다. 문의: {{CONTACT_EMAIL}}

## 1. 처리하는 정보

| 구분 | 항목 | 수집 시점 |
| --- | --- | --- |
| 계정 | Google 계정 식별자, 이메일, 이름 | Google 로그인 |
| 건강 관련 정보 | 체중, 키, 성별, 출생 연도, 운동 기록(종목·무게·횟수·RPE/RIR·휴식·메모), 1RM 측정값 | 사용자가 입력할 때. 건강정보 처리 동의를 받은 뒤에만 |
| 설정 | 단위, 기본 휴식 시간, 1RM 추정식 등 | 설정을 바꿀 때 |
| AI 연동 | 연결한 AI 서비스 이름, 연결 시각, AI가 넣은 데이터의 출처 표시 | AI 연결(MCP)·가져오기를 쓸 때 |
| 기기·보안 | Google Play 무결성 판정 결과, 접속 IP(호출 제한용) | 로그인·토큰 갱신, API 호출 |
| 오류 정보 | 앱 오류 내용, 기기 모델, OS 버전, 앱 버전 (운동 기록·이메일은 넣지 않음) | 앱 오류가 날 때 |

앱은 사진, 위치, 연락처를 수집하지 않습니다.

## 2. 이용 목적
- 운동 기록 저장과 여러 기기 간 동기화
- 프로그램 규칙에 따른 다음 회차 무게, 추정 1RM, PR, 그래프 계산
- 사용자가 연결한 AI 서비스가 프로그램·기록을 넣고 조회하도록 지원
- 부정 사용(앱 변조, 자동화된 대량 호출) 방지와 오류 수정

광고나 맞춤형 마케팅에는 쓰지 않으며, 개인정보를 판매하지 않습니다.

## 3. 제3자 제공과 처리 위탁
- **Google**: 로그인 인증, Play 무결성 검증
- **사용자가 연결한 AI 서비스**(Claude, ChatGPT, Gemini 등): 사용자가 직접 연결하고 허용한 범위에서만 프로그램·기록을 주고받습니다. 그 서비스에서의 처리는 각 서비스의 방침을 따릅니다. 앱 설정에서 언제든 연결을 끊을 수 있습니다
- **서버 호스팅 사업자**: 데이터 저장
- **오류 수집 서비스**: 오류 정보(1항의 "오류 정보")만

## 4. 보관 기간과 파기
- 계정을 삭제할 때까지 보관합니다. 계정을 삭제하면 모든 운동 기록, 신체 정보, 설정, AI 연결 정보를 즉시 삭제합니다
- 장애 복구용 백업에는 삭제 후 최대 {{BACKUP_RETENTION_DAYS}}일 동안 남을 수 있으며, 그 뒤 자동으로 지워집니다
- 호출 제한용 IP 기록은 짧은 시간 단위로만 메모리에 두고 저장하지 않습니다

## 5. 사용자의 권리
- **열람·내보내기**: 앱 설정 → AI 연동 → 내보내기에서 전체 기록을 JSON·CSV로 받을 수 있습니다
- **수정**: 앱에서 기록·신체 정보·설정을 직접 고칠 수 있습니다
- **삭제**: 앱 설정 → 계정 → 계정 삭제. 앱을 쓸 수 없으면 {{CONTACT_EMAIL}}로 요청하면 처리합니다. 자세한 절차: {{BASE_URL}}/account-deletion
- **동의 철회**: 앱 설정 → 건강정보 동의 철회. 철회하면 다시 동의하기 전까지 앱을 쓸 수 없고, 이미 저장된 기록은 계정을 삭제할 때까지 보관됩니다. 기록까지 지우려면 계정을 삭제합니다

## 6. 안전성 확보 조치
- 전송 구간 암호화(HTTPS), 접근 토큰 기기 보안 저장소 보관
- 서버 접근 권한 최소화, 호출 제한, 앱 무결성 검증
- 다른 사용자의 데이터에 접근할 수 없도록 모든 요청에서 계정 단위로 권한 확인
