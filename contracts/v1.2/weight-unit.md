# 무게 단위(kg·lb)와 무게 ± 버튼 (2026-11-28)

사용자 요청: "무게 단위 lbs kg 둘다 선택 가능해야함. 최소단위기능은 그냥 빼고 0.5 1 5 단위로 가감할수있게 변경"

## 1. 원칙
- 저장·전송·MCP 값은 지금처럼 **항상 kg**(소수 둘째 자리). 표시·입력만 설정 단위(`settings.weightUnit` = KG | LB).
- 설정 단위를 바꾸면 화면 전체(기록 입력, 목록, 그래프, 1RM, 프로그램 규칙·편집기, 요약)가 그 단위로 보인다.
- 프로그램 자동 계산(서버 엔진)도 설정 단위의 원판 기준으로 맞춘다(아래 3절).

## 2. "최소 단위(반올림 단위)" 사용자 기능 제거
- 프로그램 편집기의 '무게 단위(반올림)' 칸과 규칙 목록의 '반올림' 줄을 앱에서 없앤다. 편집기는 새 정의에 `roundingKg` 를 쓰지 않는다.
- 스키마·검증기는 `roundingKg` 를 계속 **선택 필드**로 받는다(기존 데이터·템플릿·MCP·JSON 가져오기 호환). 템플릿 JSON 의 값은 그대로 둔다(내부 값).
- 엔진의 실제 반올림 단위(effective step, kg 기준):
  1. 정의에 `roundingKg` 가 있으면 그 값.
  2. 없으면 진행 규칙들(progression 의 incrementKg, 표의 incrementKg/amount 중 양수)에서 가장 작은 값 m 을 구해, {0.5, 1, 1.25, 2.5, 5} 중 m 이하인 가장 큰 값. 규칙에 양수 증량이 없으면 2.5.

## 3. lb 사용자의 자동 계산
사용자 설정이 LB 이면, 엔진은 계산 직전에 정의의 kg 수치를 lb 원판 기준 값으로 바꿔 쓴다(정의 자체는 안 바꿈, 계산 시점 변환).
- 변환 함수 `lbFriendly(kg)`: lb = kg / 0.45359237, q = (lb >= 2.5 ? 2.5 : 1), lbR = round(lb / q) * q (동률은 올림), 결과 kg = lbR × 0.45359237 (반올림 없이 계산에 사용).
  - 예: 2.5kg→5lb, 5kg→10lb, 1.25kg→2.5lb, 1kg→2lb, 0.5kg→1lb, 20kg 바→45lb, 10kg→22.5lb.
- 대상: effective step(→ lb step), barKg, progression·표의 incrementKg/amount, Load.Fixed 의 kg, 실패 방법 SUBTRACT_KG 의 값. 퍼센트·비율·횟수는 그대로.
- derive(비율 내림)도 같은 lb step 으로 lb 공간에서 내림.
- 무게 반올림은 lb 공간에서: lb = kg/0.45359237 를 lb step 배수로(가장 가까운 배수, 동률 내림 — 기존 kg 규칙과 같음), 결과를 kg 로 바꿔 **소수 둘째 자리 kg** 로 반환. 바벨 최소는 lbFriendly(barKg).
- KG 사용자의 계산은 지금과 완전히 같아야 한다(기존 테스트·벡터 불변).
- 단위를 바꾸면 그 뒤 계산(replay 포함)이 새 단위로 다시 된다. 이미 끝난 기록은 바뀌지 않는다.
- 앱 표시: lb 는 소수 첫째 자리(`Units.format`) → 61.24kg 은 "135 lb".

## 4. 무게 ± 버튼
- 무게 입력 칸(세트 기록, 세션 편집, 예정 운동 편집, 프로그램 시작 TM/1RM 카드, TM 조정, 1RM 측정 시트, 편집기 빠진 시작 무게 등 운동 무게 칸)에 − / + 버튼과 **가감 단위 선택(0.5 · 1 · 5)**.
- 단위 숫자는 **설정 단위 기준**(kg 사용자는 0.5kg·1kg·5kg, lb 사용자는 0.5lb·1lb·5lb).
- 선택한 가감 단위는 기기에 기억(모든 무게 칸 공통, 기본 5). 체중 입력은 대상 아님.
- 기존 고정 2.5kg/5lb 스텝과 프로그램 roundingKg 기반 스텝(programStepKg)은 없앤다.
- TM 제안값(1RM×0.9 등)의 반올림은 kg 2.5 / lb 5 배수.

## 5. MCP
- 값은 계속 kg. `get_settings` 와 MCP 안내문(instructions)에 "사용자 표시 단위가 LB 면 kg 값을 lb 로 바꿔 보여 주고, 사용자가 lb 로 말한 무게는 kg 로 바꿔 넣는다"를 명시. 새 도구 없음.
